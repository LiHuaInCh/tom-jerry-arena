# 大地图与任务强化设计

## 地图

- 尺寸：2600 × 1950（当前 1800 × 1350 的 1.44 倍）
- 相机仍为固定缩放跟随，视野不变，只扩大可活动区域
- 五个区域，用不同地板材质和障碍物区分：

| 区域 | 位置 | 特征 |
|---|---|---|
| 厨房 | 左上 | 餐桌、奶酪堆，经验球多 |
| 客厅 | 右上 | 沙发、地毯，开阔适合走位 |
| 走廊 | 中部 | 狭窄，夹击风险高 |
| 花园 | 左下 | 灌木、水池，移速略降 |
| 地窖 | 右下 | 木箱、酒桶，精英与 Boss 出生点 |

- 每区域独立刷怪权重：厨房鼠多、地窖猫多，花园远程多
- 区域边缘有传送门式通道，避免长途折返

## 任务系统

每局随机 3 个任务，全部完成触发最终奖励：

| 任务类型 | 示例 | 目标 |
|---|---|---|
| 击杀 | 击倒 60 只猫 | 计数 |
| 区域 | 在厨房击倒 20 只 | 区域限定 |
| 生存 | 存活到第 8 波 | 波次 |
| 收集 | 拾取 30 颗经验球 | 计数 |
| 精英 | 击破 2 个精英 | 计数 |

## 任务奖励（三选一）

完成任务后弹三选一，奖励是**特殊强化**，不进普通升级池：

| 强化 | 效果 |
|---|---|
| 连锁闪电 | 每 3 次命中释放一次 120 范围链电 |
| 时间减缓 | 每 15 秒触发 2 秒慢动作（敌人 0.6×） |
| 护盾过载 | 护盾上限 +1，破盾时爆炸 90 |
| 元素共鸣 | 融合伤害 +40%，融合冷却 -0.5s |
| 猎手直觉 | 击杀精英回复 20% 生命并刷新技能 |
| 财富 | 经验 +35%，磁铁范围 +80 |

- 三个任务都完成后，额外给一个「终极强化」：任选上述之一并升到 2 级

## HUD

- 左上角新增任务栏：三条进度（图标 + 当前/目标）
- 完成时闪烁并弹出三选一
- 暂停面板显示任务进度

## 实现步骤

1. 扩大 `D.W/D.H`，背景按新尺寸生成，障碍物按区域重新布点
2. `createGame` 生成任务列表与计数
3. 击杀/拾取/波次事件里更新进度
4. 完成时复用升级弹窗展示特殊强化
5. HUD 任务栏 + 暂停面板接入
