# 猫鼠大作战 · 游戏设计文档（可修改版）

> 版本：当前开发版（含 57 角色 / 双模式 / 道具 / 进化 / 晋升）
> 用途：作为修改依据；每节末尾标注「调参入口」。

## 1. 产品定位

- 类型：2D 俯视角幸存者-like + 6 人乱斗
- 平台：Web（file:// 可跑）+ Android（Capacitor 打包）
- 美术：官方《猫和老鼠》立绘（标题/选角/头像/局内精灵），场景与猫敌人为程序化绘制
- 性质：非商业同人，角色版权归华纳/网易

## 2. 核心循环

1. 标题页选模式（生存/乱斗）→ 选阵营（鼠 36 / 猫 21）→ 选角色
2. 生存：无尽刷怪 → 升级三选一 → 撑波次刷分；可勾选试炼盟约提高难度与倍率
3. 乱斗：6 人混战，4 条命，180 秒或 12 杀获胜；升级拿副武器/进化
4. 结算：分数 + 经验 → 账号等级、角色熟练度、徽章

## 4. 角色

- 57 名：鼠 36、猫 21；字段见 `js/data.js` 的 `characters`
- 每名角色：`id / name / faction / title / weapon / hp / speed / radius / desc / perk / fur...`
- 招牌 10 名：jerry、tuffy、swordsman、robin、detective、tom、butch、knightcat、toots、lightning；其余 m01…/c01…
- 元素：火/冰/雷/光/暗，按武器名关键词匹配，未匹配按序号轮换

**调参入口**：`js/data.js` → `characters` 数组；`hp/speed/radius` 直接改。

## 5. 武器

### 5.1 行为类型
| kind | 说明 |
|---|---|
| orbit | 近身环绕，默认 2 刃、半径 78、命中冷却 0.45s |
| ranged | 远程弹道，冷却已 ×2、弹速已 ×0.5 |
| beam | 瞬发直线贯穿 |
| chain | 连锁闪电，逐跳 82% 伤害 |

### 5.2 数值基线
- 基础攻速 `fireRate = 1.3`
- 近战伤害 38–42，远程 14–30
- 武器进化：8 条线（平底锅/大铁锤/弓箭/叉子/骑士剑/泡泡棒/火箭筒/咸鱼），各 2 分支
- 进化效果键：`dmg / cd / splash / pierce / bounce / orbitN / orbitR`

**调参入口**：`js/data.js` → `weapons`、`evolutions`；环绕参数 `orbitR/orbitN/hitCd`。

## 6. 技能

- 每角色 1 个，名称取自官方技能；9 类：blink / shield / invuln / heal / haste / slow / stealth / beam / nova
- 冷却 5–12 秒，按角色血量/移速微调
- 按钮 = 官方技能图标 + 名称 + 冷却扇形；空格 / 点按释放
- 生存与乱斗通用；AI 会在残血/近身时使用

**调参入口**：`js/data.js` → `skills`（cd/dmg/dur/radius/pct/dist/mul），`js/skills.js` 管效果。

## 7. 升级与 build

### 7.1 生存三选一
- 池：`upgrades`（16 项），武器相关卡按当前武器类型过滤
- 关键强化：三重奏、穿透、弹射、疾风、力量、强健、护盾、爆炸弹、追踪、秘技、环绕刀刃、巨刃、学识
- 经验强化「学识」：经验 +30%/层，最多 4 层

### 7.2 乱斗升级
- 固定结构：武器升级/进化 + 换武器 + 属性
- 3/6 级：副武器二选一
- 4→5 级：进化二选一

**调参入口**：`js/data.js` → `upgrades`；`js/core.js getUpgradeChoices`；`js/arena.js getArenaChoices`。

## 8. 乱斗道具

### 8.1 地图陷阱
每 12 秒 1 个，最多 3 个：
| 陷阱 | 效果 |
|---|---|
| 夹子 | 定身 2 秒（可攻击/放技能） |
| 冰块 | 冰冻 1 秒（不能移动/开火） |
| 灰瓶 | 眩晕 1.5 秒（不能移动/开火） |

### 8.2 击杀掉落
15% 概率掉 1 个，任何人可捡，每人 1 格：
| 道具 | 效果 |
|---|---|
| 护盾 | 3 秒无敌 |
| 隐身 | 3 秒，AI 不锁定，半透明 |
| 远视 | 6 秒，索敌 +160、近战 +60、弹丸 +0.35s、伤害 +15% |
| 变大 | 8 秒，伤害 +25%（不再改变体型） |
| 随机 | 重新抽一个 |

- 玩家：右下角按钮 / E 使用
- AI：残血或随机概率自动使用
- 图标：官方道具图（`assets/item-icons`）

### 8.3 元素反应（乱斗）
| 组合 | 反应 | 效果 |
|---|---|---|
| 火+冰 | 融化 | 本次伤害 ×1.6 |
| 冰+雷 | 感电 | 周围 170 内追加 18 伤害 |
| 光+暗 | 净化 | 攻击者回复 12% 生命 |

元素持续 3 秒，同目标 2.5 秒触发一次。

**调参入口**：陷阱生成 `arena.js updateTraps`；掉率 `killFighter`；道具效果 `TJ.useItem`；反应 `damageFighter`。

## 10. 试炼盟约

| 盟约 | 效果 | 倍率 |
|---|---|---|
| 怪潮 | 刷怪间隔 ×0.8 | ×1.2 |
| 精英 | 精英概率 ×2 | ×1.2 |
| 禁血包 | 不掉血包 | ×1.3 |

倍率相乘，只影响生存；结算分数按倍率计算。

**调参入口**：`index.html` 的 `.cov` 按钮、`main.js covenants`、`core.js` 的 `g.cov` 判定。

## 11. UI / 流程

- 标题：主视觉 → 模式 tab → 阵营 tab → 角色卡（可滚动）→ 盟约 → 开始 → 最佳成绩 → 个人栏
- HUD：头像/血条/技能按钮/道具按钮/暂停/波次/击杀
- 升级弹窗：1–3 张卡（图标 + 名称 + 描述 + 稀有度）
- 详情弹窗：头像、属性条、武器、技能、天赋、元素
- 结算：分数、名次/波次、经验、徽章

**调参入口**：`index.html` 结构、`css/style.css` 样式、`main.js` 流程。

## 13. 平衡目标（建议）

- 生存：普通玩家 4–7 分钟，10 分钟内必死；第 5/10/15 波死亡率约 30%/60%/85%
- 乱斗：单局 2–3 分钟；每角色胜率 40–60%
- 升级节奏：前 3 分钟每 20–30 秒一次三选一

## 16. 元素/增幅/符文/压力/盟约（v2 新增）

### 16.1 元素与融合
- 5 元素：火/冰/雷/光/暗；武器槽 elemSlots[2]，可注入，双槽 +10% 伤害
- 融合 10 组：野火(暴击)、极寒(冻结0.8s)、雷鸣(150连锁12)、圣辉(回2%)、侵蚀(易伤3s)、融化(×1.6)、感电(170内18)、净化(回12%)、爆燃(90溅射30%)、霜蚀(减速2.5s+×1.1)
- 反应冷却 2.5s/目标；生存敌人元素：小猫光、鱼骨冰、肥猫火、扑扑雷、汤姆暗、斯派克光

### 16.2 行为增幅（4→5 级二选一）
- 蓄力重击（大铁锤）：每第3次命中2.2×，攻速-15%
- 定点炮台（咸鱼/远程兜底）：静止0.8s后射速×2，弹速-30%
- 轨道扩张（平底锅）：环绕半径×1.6，命中间隔+0.2s
- 迟滞泡沫（咸鱼）：命中减速1.5s，伤害-10%
- 贯穿分裂（侦探放大镜）：主束后左右45°各一道60%短束
- 传染过载（电流球）：跳数+2，衰减82%→60%
- 进化查找：先按武器名，再按类型兜底（orbit→大铁锤，ranged→咸鱼）

### 16.3 符文
- 点数：角色熟练度每2级+1，账号上限30
- 锐利(伤害+2%/级)、疾行(移速+1.5%/级)、求知(经验+3%/级)、坚韧(生命+2%/级)，各5级，免费重置
- 存档 tj_meta_v2，自动从 v1 迁移

### 16.4 压力槽
- 伤害累积 +dmg×0.004，每秒-0.5，上限100
- 40–75 刷怪×0.85；75+ ×0.7

### 16.5 试炼盟约
- 怪潮：刷怪×0.8，分数×1.2
- 精英：概率×2，分数×1.2
- 禁血包：不掉血包，分数×1.3

### 16.6 晋升与熟练度
- 账号等级：分数÷10 + 击杀×2；每级+1%伤害/+0.5%移速/+1%经验
- 熟练度：每3次使用+1级（上限10），每级+0.5%伤害
- 徽章：初阵/盟约/Lv5/十人
