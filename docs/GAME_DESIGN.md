# 猫鼠大作战 · 当前版本说明书

> 版本：v2（元素融合 / 行为增幅 / 符文 / 压力 / 盟约 / 晋升）
> 平台：Web + Android（Capacitor）
> 性质：非商业同人，角色版权归华纳兄弟 / 网易

## 1. 游戏概述

- 类型：2D 俯视角幸存者-like + 6 人乱斗
- 操作：移动 + 自动瞄准开火 + 一个主动技能 + 一个道具位
- 内容：57 名角色（36 鼠 / 21 猫）、10 组元素融合、8 条武器进化、3 种誓言难度
- 目标：生存模式刷分挑战波次；乱斗模式 6 人混战排名

## 3. 角色

- 57 名：鼠 36、猫 21；数据在 js/data.js characters
- 字段：id / name / faction / title / weapon / hp / speed / radius / desc / perk / 元素
- 招牌 10 名有固定 id：jerry、tuffy、swordsman、robin、detective、tom、butch、knightcat、toots、lightning，其余为 m01… / c01…

- 选角卡右下角「详情」可看属性、武器、技能、天赋、元素

## 4. 武器

### 4.1 类型

| 类型 | 行为 |
|---|---|
| orbit | 近身环绕，默认 2 刃、半径 78、命中冷却 0.45s |
| ranged | 远程弹道（冷却已 ×2、弹速 ×0.5） |
| beam | 瞬发直线贯穿 |
| chain | 连锁闪电，逐跳衰减 |

基础攻速 fireRate = 1.3。

## 5. 技能

- 每角色 1 个，名称取自官方技能；9 类：blink / shield / invuln / heal / haste / slow / stealth / beam / nova
- 冷却 5–12 秒；按钮显示官方图标 + 名称 + 冷却扇形
- AI 会在残血或近身时使用

## 6. 元素与融合

### 6.1 获取

- 开局两个元素槽为空（不再有初始元素）
- 7 级：升级只出两张元素卡，5 选 2 二选一，填第 1 槽
- 14 级：再抽两张，不排除第 1 槽元素，可选同元素
- 元素卡显示：定位 + 可形成融合及效果；14 级显示与已有元素的具体融合

### 6.2 规则

- 命中挂 3 秒元素状态；同目标 2.5 秒触发一次融合
- 双槽额外 +10% 伤害
- 乱斗 10 组全部生效；生存目前实现伤害类融合

| 光+光 | 圣辉 | 回复 2% 生命 |

## 10. 升级与强化

### 10.1 生存三选一

- 16 项通用强化（三重奏、穿透、弹射、疾风、力量、强健、护盾、爆炸弹、追踪、秘技、环绕刀刃、巨刃、学识等）
- 武器相关卡按武器类型过滤：环绕角色不出远程卡，远程角色不出环绕卡
- 学识：经验 +30%/层，上限 4 层

### 10.2 乱斗升级

- 固定结构：武器升级/进化 + 换武器 + 属性
- 3/6 级：副武器二选一
- 4→5 级：进化二选一

## 13. 压力槽

- 伤害累积 +dmg×0.004，每秒 -0.5，上限 100
- 40–75：刷怪 ×0.85；75+：×0.7

## 14. 界面与流程

- 标题页：主视觉 → 模式 → 阵营 → 角色卡（可滚动）→ 盟约 → 开始 → 最佳成绩 → 个人栏（等级/经验/徽章/符文）→ 玩法说明
- 玩法说明：基础操作 / 生存 / 乱斗 / 元素融合 / 成长 / 小提示
- 暂停：显示本局数据（时间、波次或击杀、分数、等级、伤害/移速倍率），可继续、结束本局
- 结束本局：立即结算（记录经验、熟练度、徽章）后回主页
- 结算：分数、名次/波次、经验、徽章

## 17. 平衡目标

- 生存：普通玩家 4–7 分钟，10 分钟内必死；第 5/10/15 波死亡率约 30%/60%/85%
- 乱斗：单局 2–3 分钟，每角色胜率 40–60%
- 升级节奏：前 3 分钟每 20–30 秒一次三选一

## 18. 已知限制

- 生存模式的控制/回复类融合（极寒、雷鸣、圣辉、感电、净化）尚未实现，仅乱斗生效
- 57 个角色天赋目前按 6 类属性模板生成，未逐角色定制
- 部分角色近战/远程仍依赖关键词与类型兜底，建议维护手工对照表
- 远视为数值近似（索敌/射程/伤害），不是真正视野
- APK 为 debug 签名，正式分发需 release 签名
