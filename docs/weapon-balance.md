# 武器基础数值平衡

## 目标

让 18 个流派的基础输出接近，再靠成长曲线区分前后期。

## 基础伤害倍率

| 流派 | 倍率 | 说明 |
|---|---|---|
| 远程 | ×2.2 | 原数值偏低 |
| 光束 | ×3.0 | 单体直线，补偿无穿透 |
| 连锁 | ×1.7 | 多目标递减 |
| 链接 | ×1.4 | 持续连接 |
| 环绕 | ×0.62 | 原数值过高 |
| 召唤 | ×0.62 | 配合 4 秒冷却、3 只同时在场的重做 |
| 光环 | ×0.9（伤害与持续伤害同时生效） | 范围持续 |
| 布置 | ×0.9 | 陷阱触发 |

## 理论 DPS 分布（修正后）

| 分位 | DPS |
|---|---|
| 最低 10% | 34 |
| 中位数 | 58 |
| 最高 10% | 120 |

极值：玛丽/表演者杰瑞约 30，塔拉/恶魔杰瑞约 194（追踪/抛射实际命中率低于理论值）。

## 配套改动

- 召唤武器：4 秒冷却、10 秒持续、基础 3 只、上限 5 只、单次伤害倍率 1.3
- 光环：aegis 也补上持续伤害字段
- 敌人：血量成长 14%/波，6~11 波额外 ×1.12，伤害成长 4.3%/波，Boss 血量系数 0.6/0.7/0.7/1.05

## 当前生存结果（57 角色 × 3 局）

第 5/10/15 波：78% / 52% / 13%

第 15 波达标，第 10 波仍偏高 12 个百分点；单机器人模拟在该区间波动较大，继续微调收益有限。
